## About

I am a **Java Backend Developer** focused on building reliable, maintainable and scalable backend systems using the Spring ecosystem.

My primary engineering focus is **Java, Spring Boot, Spring Data JPA, Hibernate, REST APIs, relational databases and backend architecture**. I am particularly interested in understanding how backend systems work internally — from HTTP requests and service-layer orchestration to persistence, transactions, authentication, auditing and database operations.

I also explore **AI-powered backend engineering**, combining Spring Boot with modern AI capabilities to build systems where large language models interact with real backend services and infrastructure.

Currently focused on:

* Backend development with **Java & Spring Boot**
* RESTful API design and layered architecture
* JPA, Hibernate and relational database design
* Authentication, authorization and auditing
* Distributed systems and scalable backend architecture
* AI-integrated backend applications
* Data structures and algorithms for software engineering interviews

**Open To:** Java Backend Developer • Spring Boot Developer • Software Engineering Internships • Backend Engineering Opportunities
